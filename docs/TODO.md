### Already fixed in this session (do not re-report)
- `LocalDate.ofInstant` is API 34 — would have crashed the whole feature on Android 8–13.
  Replaced with `Instant.atZone().toLocalDate()`. Lint's `NewApi` error caught it; note the
  project sets `abortOnError = false`, so a lint error does **not** fail the build.
- The notification deep link was not observable by Compose, so a tap while the app was
  already open did nothing. `EventDeepLink` now exposes a `StateFlow`.
- The in-app preview showed titles written for delivery night ("… tonight") next to a date
  days away. `previewTitle()` strips the suffix for anything not happening today.
